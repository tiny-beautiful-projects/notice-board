# Notice Board Project
스프링 부트(Spring Boot)를 기반으로 구축된 간단하고 효율적인 게시판 웹 애플리케이션입니다. 사용자 소통과 게시글 관리를 위한 기본적인 CRUD 기능을 제공합니다.
---

## 🛠 Tech Stack (배포 및 개발 스택)

### **Backend**
* **Language**: Java 17
* **Framework**: Spring Boot (Gradle Build)
* **Build Tool**: Gradle

### **Infrastructure & Deployment**
* **Cloud Platform**: AWS EC2 (Ubuntu, `t3.micro` 프리티어)
* **Domain & DNS**: Cafe24 (Domain Registrar) + AWS Route 53 (Public Hosted Zone)


## ⚙️ Project Features
* 게시글 작성
